# SciCloud AGI V40.60 · Autopilot Studio

V40.41～V40.60 大阶段：从一键生产一集继续向 AI 导演自动驾驶推进。

## 新能力
- 人物/场景一致性锁与指纹
- 镜头级可恢复生产队列
- 镜头 Prompt/约束准备
- AI 导演自动驾驶入口
- Episode 状态、阻塞、恢复
- 发布素材包 ZIP
- 统一自动驾驶控制台

## 重要原则
没有真实图像/视频/TTS 模型时，不生成假文件、不伪造成功；系统明确显示 blocked，并保留任务供配置能力后继续。

## 本地优先
项目数据继续保存到项目目录，可放在 1TB 外接硬盘；模型通过 Model Hub / ComfyUI 等适配器接入。
