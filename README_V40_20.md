# SciCloud AGI V40.20.0 — AI导演核心闭环

本版本把 V40.12～V40.20 作为一个批量开发阶段交付。

## 新增能力
- V40.12 跨镜头连续性导演：检测人物、场景、方向、机位、光影变化并形成联动修复组。
- V40.13 自动分镜修复：把导演决策转换成具体镜头修改动作。
- V40.14 多镜头联动修复：相邻镜头一起修复，避免只修一个镜头造成新的断裂。
- V40.15 故事级 QC：检查故事/人物/场景/分镜/Prompt 产物和跨镜头连续性。
- V40.16 导演修复规划器：将人物、场景、镜头、构图、光影、动作、Prompt 问题映射到最小任务链。
- V40.17～V40.19 导演循环基础：审核 → 决策 → 修复计划 → 任务重排 → 再审核。
- V40.20 AI导演核心闭环：统一 Director Loop 接口，保留真实产物原则，不伪造视觉评分或生成结果。

## 原则
视觉语义判断仍必须由真实 Vision 模型提供；未配置 Vision 模型时，系统只做文件/结构/连续性检查，不冒充 AI 看懂画面。

## 下一阶段
V40.21～V40.30：本地图片、视频、TTS、音效、字幕、自动剪辑、FFmpeg 成片导出与生产适配器强化。
